# Ban One Class

What would the Hearthstone ladder look like if every player could ban one class they never get matched against?

This page simulates it per rank bracket, using matchup and play-rate data from Vicious Syndicate's Data Reaper reports (#360 and #359). All data credit goes to [Vicious Syndicate](https://www.vicioussyndicate.com/).

Open `index.html` in a browser, or visit the GitHub Pages site for this repo.
